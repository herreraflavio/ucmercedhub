UC Merced Hub mobile application announcements

Promotional content UC Merced Hub mobile app announcements and opportunities.

  • Now live on iPhone

    UCM Hub is now live on the App Store.

    Visually explore and navigate UC Merced campus in real time. The iOS app helps students, faculty, and visitors discover campus events faster with an interactive map built for quick exploration.

    • Interactive event mapping across campus
    • Instant event details and room information
    • Date filters for today, this week, and upcoming events
    • Map Feed for switching between specialized campus maps
    Download on the App Store Explore Web Version

    Questions, partnerships, or feedback: contact@ucmercedhub.com

  • Android internal testing

    Android internal testing is now underway.

    Discover what is happening at UC Merced in real time with the Android version of UCM Hub. Internal testing is open for early feedback before the broader launch.

    • Interactive event mapping with zoom and pan exploration
    • Event times, rooms, descriptions, and location details
    • Real-time GPS directions to buildings and events
    • Date filtering for current and upcoming events
    Join Internal Testing Support Page

    Interested in testing or collaborating: contact@ucmercedhub.com
